## System Overview
- **App Name:** WeirdAge
- **Concept:** Translates standard chronological age into visceral, surprising, and aesthetically arresting metrics (Days, Hours, Minutes, Seconds, Sundays, Lunar Orbits, Solar Mileage).
- **Core Loop:** Enter birthday -> Get weird statistics -> React -> Share (1080x1920 card).
- **Aesthetic:** Industrial-Minimalist / Brutalist (Colter / Slughouse Standards).
- **Typography:** Fira Code Bold (Monospace telemetry) + Clean Grotesk.
- **Monetization:** Frictionless $0.49 Pro Pass (StoreKit & Google Play ready).
- **Offline / Privacy:** Zero network dependencies for core calculation; zero tracking.
